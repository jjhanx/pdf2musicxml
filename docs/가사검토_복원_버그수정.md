## 가사 검토 데이터 복원 버그 수정

- **문제점**: 2단계 가사 검토 중 UI에 가사 데이터가 비어있는 상태에서 `review_backup.json`을 업로드하여 복원할 때, 빈 배열에 map을 돌려 복원이 무시되고 빈 데이터가 서버로 전송되어 `lyric_manifest.json`이 1KB 크기로 생성되는 문제 발생.
- **해결책**: `App.tsx`의 `handleUploadReview`에서 백업 데이터의 항목 중 기존 `reviewData`에 없는 누락된 항목(missing)을 식별하여 `reviewData` 배열에 추가하고 정렬하도록 수정. 이를 통해 3단계에서 가사가 유실되는(분리된 가사가 없습니다) 에러를 방지함.
